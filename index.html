Задача

Создать собственное S3-хранилище под архивы, бэкапы и медиа без облачных тарифов.

Решение

Кластер из 4 нод RustFS с избыточным кодированием и балансировкой через Nginx TLS.

Результат

Сохранение доступности данных на чтение и запись даже при выходе узла из строя.

  • Распределение блоков и чётности Erasure Coding между 4 узлами.
  • Терминация шифрования и health-check балансировка на Nginx TLS 1.3.
  • Связность узлов поверх защищённого туннелированного контура OpenVPN.
  • Полная совместимость со стандартными клиентами AWS S3 SDK и бэкапами.

Уйти от проприетарных VMS с поканальной оплатой при масштабировании на 200+ точек.

Решение

Кластер Frigate NVR с декодингом на Intel iGPU, рестримом go2rtc и сетью WireGuard.

Результат

Мгновенный WebRTC-просмотр витрины камер, умный архив и 100% экономия на лицензиях.

  • Бесшовный рестриминг потоков в браузер через go2rtc (WebRTC / MSE).
  • Автоматический опрос доступности RTSP-потоков демоном cam_monitor.

Задача

Исключить потери техники при перемещениях между складом ИТ, ремонтом и 193 точками.

Решение

Система Snipe-IT в Docker за Caddy HTTPS со сквозной маркировкой штрихкодами TBK.

Результат

Полная история каждой кассы, сканера и ПК за 2 секунды с ротацией бэкапов на NAS.

  • Единый стандарт инвентарных меток TBK-xxxxx со штрихкодами Code 128 и QR.
  • Внутренний центр сертификации и HTTPS-терминация через Caddy PKI.
  • Разграничение прав доступа администраторов и полный аудит выдач/возвратов.
  • Ежедневный дамп БД и файлов в 02:00 по Cron на SMB-хранилище (30 дней).
